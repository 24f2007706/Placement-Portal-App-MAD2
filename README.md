# 🎓 Placement Portal

A full-stack Placement Portal designed to streamline campus recruitment and placement activities by connecting students, recruiters, and administrators through a centralized digital platform. The application simplifies job posting, application management, candidate tracking, and placement monitoring with role-based access control and database-driven workflows.

## 🚀 Features
### Student Module

* Create and manage profiles
* Browse available job opportunities
* Apply for placement drives
* Track application status
* Manage academic and personal information

### Recruiter Module

* Post job openings and placement drives
* Review student applications
* Shortlist candidates
* Update recruitment status
* Manage company information

### Admin Module

* Manage users and recruiters
* Monitor placement activities
* Approve and manage job postings
* Generate placement statistics
* Maintain platform integrity

## 🛠️ Tech Stack

* **Backend:** Flask, Python
* **Database:** SQLite
* **Frontend:** HTML, CSS, JavaScript
* **Templating Engine:** Jinja2
* **ORM:** SQLAlchemy

## 🎯 Project Objectives

The Placement Portal aims to modernize campus recruitment by providing a centralized platform for students, recruiters, and administrators. The system reduces manual coordination, improves transparency in recruitment processes, and enhances placement management efficiency.
