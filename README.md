PROJECT DISCRIPTION 
Project is about Placement Cell System, in which admin , company and student dashboards to be created every dashboard will do their own different works . Where admin is a super user which will handle almost all works happening in placement cell . In short we have to create full atmosphere of placement cell from registration of student to getting placed .  

TECHNOLOGIES USED 
Flask – for API’s. 
Flask-SQLAlchemy - for database connection. 
VueJS  - for UI ( html ,css ). 
Redis and Celery - for batch jobs and caching.
